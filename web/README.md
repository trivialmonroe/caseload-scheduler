# Caseload Scheduler — web app

Open `index.html` in a browser (double-click, or serve this folder). No install, no Google account.

- **Workspace JSON** is the full file (settings, caseload, schedule). Auto-saved in `localStorage`; download/open anytime.
- **CSV** import/export per table (students, hours, grades, student blocks, schedule). Headers are listed on the Import / export page.
- **Generate schedule** runs the same engine as the Sheets build. Week view, coverage, session locks, alternate times, and open-slot grids are all in the sidebar.

`engine.js` must sit next to `index.html`.
